# v0.6.1 — Unified source coverage catalog

## Documentation model

This corrective release replaces implementation-wave terminology with one permanent,
olympiad-neutral coverage model. No corpus was removed or downgraded, and no
olympiad-family identity changed.

All families now use the same public documentation system. The repository-wide
source catalog represents content state, completeness, access, provenance, and
redistribution independently. The generated family coverage table summarizes every
catalogued family without grouping competitions by when they entered the archive.

## Aligned surfaces

- The source audit became `data/audits/source_coverage.csv` and now covers all 53
  configured sources plus 9 evaluated unresolved or deferred candidates.
- README EN/RU, publishing policy, contributor guidance, generated coverage report,
  and release documentation use the same neutral terminology.
- Source-specific evidence and lineage boundaries remain intact.

## Corpus unchanged

- Configured source seeds: 53
- Discovered candidates: 3,768
- Indexed physical files: 3,538
- Olympiad index rows: 687
- Relation groups: 592
- Families with indexed local files: 27
- Families represented in the olympiad-level index: 32

This is a documentation and catalog migration, not a data-ingestion release. Local
olympiad binaries remain ignored and are not attached to the GitHub release.
