# v0.8.0 — preserved correspondence archive and snapshot stability

## Highlights

- Added the Russian Open Correspondence School Astronomy Olympiad as a
  first-class family.
- Preserved four Russian tasks-with-solutions PDFs for 2005–2008 under the new
  narrow lost-publication exception in `data/preserved/`.
- Added a checksum manifest with byte sizes and SHA-256 values for every preserved
  source file.
- Documented the preservation policy for historically public material whose
  original hosting disappeared for technical or archival reasons and whose
  republication is explicitly permitted.
- Added deterministic ingestion of repository-preserved source files without
  treating them as network downloads.
- Made family-scoped pipeline runs snapshot-safe: `run_pipeline.py --families ...`
  can update local acquisition state but restores the tracked repository-wide
  public snapshot byte-for-byte before returning.
- Replaced sequential relation-group identifiers with stable bucket-derived IDs.
- Migrated all existing relation groups to the stable identifier scheme without
  changing their semantic grouping.

## Public snapshot

- Configured source seeds: 55
- Discovered candidates: 4,057
- Indexed physical files: 4,179
- Olympiad index rows: 797
- Relation groups: 740
- Families with indexed local files: 29
- Families represented in the olympiad-level index: 34
- Evaluated source-coverage rows: 65 (55 currently configured)

## Russian Open Correspondence School Astronomy Olympiad

- Added preserved publications for 2005, 2006, 2007, and 2008.
- Each physical PDF contains both tasks and solutions and is indexed with those
  logical document types.
- The four preserved files are committed only because they satisfy the documented
  preservation exception: they were historically public, disappeared from public
  hosting for technical reasons, and republication of the exact material is
  explicitly permitted.
- Private provenance correspondence is intentionally not committed.
- The preserved corpus is bounded and tracked by repository path, year/context,
  byte size, and SHA-256.
- The preserved 2005 publication year is not presented as an independently
  verified founding year of the competition.

## Snapshot and relation stability

- Focused `--families` runs no longer replace the tracked global manifests and
  indices with partial-family output.
- Family-scoped cleanup leaves tracked discovery metadata intact while still
  clearing selected-family local download/checkpoint/normalization state.
- Relation-group IDs now derive from the relation bucket, for example
  `rg--czech-astronomy--2020--regional--solutions`, rather than from traversal
  order.
- The migration retains all 740 relation groups: semantic groups added = 0,
  semantic groups removed = 0, and every new group ID is unique.

## Validation

- Full unit-test suite passed: 66 tests.
- `git diff --check` passed.
- A focused clean rebuild of `russia_correspondence_astronomy` left all tracked
  public snapshot files byte-for-byte unchanged.
- The relation-group migration was compared semantically against the previous
  snapshot: 740 groups before, 740 after, with no semantic additions or removals.
- No ordinary downloaded olympiad binaries are added to the release. The only
  committed PDFs are the four explicitly approved `data/preserved/` source files;
  they are included through GitHub's normal source-code archive and are not
  attached as separate release assets.
