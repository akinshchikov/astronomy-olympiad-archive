# v0.7.0 — Belarus and Bulgaria archive expansion

## Highlights

- Added the Belarusian Republican Astronomy Olympiad as a first-class family.
- Added bounded BelAstro discovery for district, regional, and republican/final
  materials covering 2000–2025.
- Preserved legacy Belarus DOC/DOCX/RTF/JPG/PNG materials and authoritative
  academic-year/stage metadata during normalization.
- Expanded the Bulgarian Astronomy Olympiad archive through the historical public
  pCloud folder linked by the official `astro-olymp.org` archive.
- Added Bulgarian municipal/regional/national, grade-band, theoretical/practical,
  and national-test metadata handling.
- Retained `oap.bg` as unresolved legacy provenance rather than making a dead
  endpoint a runtime dependency.
- Refreshed the global public manifests, indices, coverage report, and snapshot
  counts.
